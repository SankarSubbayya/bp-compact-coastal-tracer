# Mass-conserving, bound-preserving compact tracer transport on time-varying control volumes

Reproducibility package for:

> S. Sankaranarayanan, "Mass-conserving, bound-preserving compact tracer transport on time-varying
> control volumes," submitted to the *Journal of Computational Physics* (2026).

Every number and results table in the paper is generated by `paper/make_tables.py` from the result files in
`paper/`, and every figure by the scripts listed in `paper/REPRODUCE.md`. The manuscript itself is not part of this
package.

## Layout

- `paper/`: drivers, result files (`*.json`, `*.npy`), generated `numbers.tex` and `tables/`, `figures/`,
  benchmark data in `figure_data/`, and `REPRODUCE.md` (the order in which the scripts run, with run times).
- `_dev/`: helper modules imported by the drivers; `_dev/sfbay_fine/` holds the San Francisco Bay grid,
  calibration and model records.
- `MANIFEST.sha256`: SHA-256 of every file. The two offline-transport flux files (`fluxes_mixed.npz`, 224 MB;
  `fluxes_mixed_25h.npz`, 918 MB) are not included; step 3 of `REPRODUCE.md` regenerates them and the manifest lists
  their checksums.

## Quick checks

Python 3.12 or later with numpy, scipy and matplotlib. From `paper/`:

```
uv run --with numpy --with scipy python3 make_tables.py
```

regenerates `numbers.tex` and `tables/` from the result files, with assertions on every claim the text makes, and
checks that each figure was drawn by its script from the current results (`figure_provenance.py`). The figure scripts
(step 11 of `REPRODUCE.md`) run with `uv run --with numpy --with scipy --with matplotlib python3 <script>`;
`gen_revision_figures.py` also needs `fluxes_mixed.npz` from step 3 for the bay map. The full sequence of experiments is in
`paper/REPRODUCE.md`; the compiled timings need numba.

## Data

The bathymetry is a subset of the NOAA NCEI Coastal Relief Model and the tidal constants are those of NOAA station
9414290 (Golden Gate); `fetch_crm.py` retrieves the bathymetry from NOAA. Both are U.S. Government works.

## Versions

- `v2.0.1-jcp` (this version): the package of the *Journal of Computational Physics* submission.
- `v2.0.0-jcp`: the same package before the steep-shelf runs with the dissipation term and with a finer reference
  quadrature (`steep_depth_dissip.json`, `shelf_reference_check.json`) and before the stricter slotted-cache check.
- `v1-ocean-engineering-2026-08`: the earlier package of the *Ocean Engineering* submission (different layout).
